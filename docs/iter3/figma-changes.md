iter2 의 [F-0 ~ F-17](../iter2/figma-changes.md) 에 이어 번호를 붙였다. 파일 `FoiB0Q7bTIjUsjhiQLefJQ`, 페이지 Proposal UI `0:1`.

- 화면을 바꾸는 항목은 **Figma 를 먼저 고치고** 그 프레임대로 코드를 짰다(사용자 지시 11-01 "디자인적인 부분은 figma에 먼저"). 아래는 모두 Figma 에 반영돼 있다. 명세만 남기고 못 그린 것은 없다.
- 새 색·반경·간격 값은 만들지 않았다. 새로 그린 채움은 모두 기존 `JitTokens` 변수에 묶었다(`color/surface`·`color/accent`·`color/amber` 등). 글꼴은 Noto Sans KR.
- 새 프레임은 보드의 빈 칸에 두고, 옆 캡션은 기존 보드처럼 "화면 이름 — 설명" 으로 달았다. 위치는 아래 "보드 위치" 표. 메인 체크아웃 `docs/instruction.md` §14.3 표에도 같은 줄을 넣어야 한다(그 파일은 git 밖이라 이 브랜치에서 고치지 않았다).
- 항목 번호(todo)는 [front-iter3.md](front-iter3.md) 의 번호와 같다.
