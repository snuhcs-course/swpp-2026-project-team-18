## 김진호

### 완료한 작업

- `origin/main`의 `c3ea88f`에서 `front-iter5` 작업 트리를 만들고 JustInTime의 Android·서버 계약·기존 Iteration 4 자료를 검토했어요. 작업 폴더는 `SWPP-PJ-front-iter5`예요.
- [Figma Iteration 5 화면](https://www.figma.com/design/FoiB0Q7bTIjUsjhiQLefJQ?node-id=711-2500)을 먼저 설계했어요. 약속방 목록·생성·코드 참가·멤버 알람, 알람 근거·확인, 이동 진행, 집 이름 변경, 알림 안내를 기존 컴포넌트·변수로 만들었어요.
- 측위 좌표를 관측 JSON에서 제외하고 이전 대기 큐도 정리했어요. 이동 중·출발 전 경로 요청을 끄고, 검색·지도 요청에 GPS 좌표가 섞이지 않게 했어요. 기기의 출발·도착 판정과 진행률은 계속 동작해요.
- 도움말의 옛 버튼 이름과 주요 문구·확률 기호를 정리했어요. 알람 상세에 측정/고정 근거·이동 보정 횟수·확률을 모르는 이유를 표시하고, 재계산된 알람을 다시 확인할 수 있게 했어요. 실제 LLM 요약에만 `AI 요약`을 표시해요.
- 이동 탭에서 진행률·도착 예상·도착 기록을 직접 보여 주도록 연결했어요. 집 이름 변경을 기존 서버 PATCH에 연결했고, 앱 알림 또는 알람 채널이 꺼졌을 때 홈에서 설정으로 안내해요.
- 약속방 프론트엔드와 저장소·ViewModel·서버 계약 제안·테스트를 구현했어요. 서버 미지원 상태를 안내하고, 멤버의 집·경로·이메일을 화면 모델에 담지 않아요. 실제 서버 기능 완료와는 구분해요.
- 수동 `AppContainer`와 저장소 인터페이스를 도입하고, 이동·알람 시각 선택·내 정보 로직을 테스트 가능한 ViewModel로 분리했어요. 화면에서 직접 하던 API 호출도 저장소로 옮겼어요.
- 공통 입력·도움말·경로·지도·변경 화면의 작은 글자와 터치 영역을 보완하고 경로 색 범례를 추가했어요.
- 설치 안내서, 알람·배터리 실측 양식과 분석 도구를 준비했어요. 빌드·테스트·서명·에뮬레이터 결과는 [검증 기록](frontend-verification.md)에 남겨요.

- 추가 요청한 S-4 `telemetry_daily`를 구현했어요. 날짜·버전·베타 사용자 필터, CSV, 기능별 횟수·p50/p95·오류율, QA 계정의 집계·학습 제외를 포함해요. 기존 API 헤더로 버전을 기록하고 새 이벤트 API는 만들지 않았어요. 백엔드 전체 pytest 2,500개가 통과했어요. [실행·주의점](telemetry-daily.md)과 [검증 결과](evidence/telemetry-tests.json)를 남겼어요.

### 남은 작업

- S-4 서버 코드의 추가형 마이그레이션 3개와 `train_models --users --verbosity 0` 전체 재학습은 배포 담당자가 실행해야 해요. 12월 12~13일에 베타 12월 7~11일 CSV를 보관해야 해요. S-6 사용자·주별 정시율·미룸·준비/이동 MAE 명령은 베타 전 후속 작업으로 남아요.
- 좌표 없는 관측을 받는 서버를 먼저 또는 앱과 함께 배포한 뒤 실서버 업로드를 확인해야 해요. 약속방도 BE 구현·계약 합의 후 개인 Event·멤버 알람까지 연동 검증해야 해요.
- 실기기에서 설치→가입→집 설정→첫 알람을 혼자 완료하는 US-25/AT-32 검증과 AT-24 7일 연속 알람·배터리 측정이 남았어요. 가능한 다음 7번의 아침은 11월 28일~12월 4일이에요. 7일 측정으로 30일 무누락을 입증했다고 쓰지 않아요.
- Accessibility Scanner의 주요 화면 5개 결과와 TalkBack·큰 글자 실제 탐색을 남겨야 해요. 에뮬레이터 화면 테스트와 소스 점검은 이 결과를 대신하지 않아요.
- 전체 `HomeViewModel` 분리는 계속 진행해야 해요. 홈 목록·일정 편집/경로 선택 등의 책임이 남아 있어요. 예상형 뒤로 가기 미리보기와 UAT 2차 밀도 피드백 반영도 남았어요.
- ‘늦게 일어남’ 화면 매핑은 준비했지만 BE가 `wake_late`를 알람 로그로 판정해 보내야 해요. 준비 항목이 늦어졌을 때 확률을 다시 계산하고 경고하는 US-17/AT-20은 BE 계약·범위 결정이 필요해요.
