# Iteration 5 프론트엔드 접근성·문구 점검

기준: Figma 문구 가이드 `554:1897`, 경로 색 안내 `547:1415`, Iteration 5 화면 `711:2500` 및 이동 지도 `711:2809`.

## 코드에서 반영한 항목

- 공통 입력·버튼·장소 선택, 도움말·문의·정시 확률 설명, 경로 선택·범례, 출발지 선택, 장소·경로 지도의 명시적인 8~11sp 보조 글자를 12sp 이상으로 조정했다. 공유 pill의 글자 크기 매개변수도 12sp 미만이 되지 않게 했다.
- 공유 pill, 날짜·시간 값 선택, 검색 버튼, 비밀번호 보기·숨기기, 장소 변경·지도·더 보기·정렬, 도움말 질문과 작은 버튼, 경로 묶음 탭, 지도 재검색·경로 전체 보기의 영역을 48dp 이상으로 확보했다. 작은 아이콘 도형 자체의 크기는 장식 크기이며 터치 영역과 구분했다.
- 검색·비밀번호·지도·교통수단 선택 동작에 Button/Tab 역할을 추가했다. 출발지 선택 여부는 부모 행의 선택 상태로 제공하고 체크 아이콘은 중복 낭독을 막기 위해 장식으로 처리했다.
- 경로 색 막대 아래에 같은 색의 표식과 도보·대기·노선 이름을 함께 표시한다. 지도 미리보기에도 같은 범례를 사용한다. 색 구분만으로 의미를 파악하지 않아도 된다.
- 현재 위치 마커의 ‘정확도 정보 없음’은 ‘정확도를 아직 알 수 없어요’로 바꿨다. 서버 처리 결과를 사실과 다르게 단정하는 문구를 추가하지 않았다.

## contentDescription 점검 판단

`contentDescription = null`은 일괄 제거하지 않았다. 이번에 확인한 공통/도움말/경로 컴포넌트에서 텍스트와 나란히 있는 검색·종류·수단 아이콘, ‘선택’ 텍스트 옆 체크, 도움말 공식의 알람 그림은 중복 정보를 제공하는 장식이다. 이들은 null을 유지한다. 텍스트가 없는 닫기·정보 버튼은 기존 `JitIconCircleButton`/`InfoButton`의 구체적인 라벨을 사용하며 48dp 영역을 확보한다. 지도 장소 핀과 현재 위치 마커는 Canvas의 별도 semantics로 이름·선택·정확도를 전달한다.

## 소스 스캔

2026-11-27 기준, `ui/common`, `ui/help`, `RouteChoiceScreen`, `TransitVisuals`, `OriginSheet`, `MapPickScreen`, `RouteMapCard`에서 `fontSize = 8/9/10/11.sp`를 검색한 결과 명시적으로 남은 항목은 없다. 작은 크기의 로딩 표시, 점·선, 지도 아이콘, 도형과 저작권 표시는 각각 텍스트 크기나 터치 동작과 구분해 검토했다.

‘~음/~됨’, ‘합니다/됩니다’ 검색은 주석·데이터·짧은 상태 라벨도 함께 잡으므로 결과를 곧바로 사용자 문구 결함으로 세지 않았다. 이번 검토 범위의 문장형 안내는 해요체로 유지했고, 선택은 semantics 상태로 전달하도록 정리했다. 프로젝트 전체의 12sp 미만 글자와 모든 화면의 대비를 검증했다는 뜻은 아니다.

## 기기에서 남은 확인

QA 에뮬레이터에서 집 관리 화면을 1.5배 글자로 표시하고 이름 변경·기본 집·삭제 동작이 보이며 48dp 이상인지 확인했다. [캡처](evidence/screenshots/iter5-frontend/homes-large-font.png)와 [24개 화면·초기화 테스트 로그](evidence/device-smoke.log)를 남겼다.

Android Accessibility Scanner의 주요 화면 5개 스캔과 TalkBack 실제 탐색, 앱 전체의 큰 글자·화면 확대 상태, 밝기·대비는 이 검사만으로 완료할 수 없다. 실제 결과와 화면 증거를 남긴 뒤 N31을 최종 완료로 바꿔야 한다. 이 문서는 Scanner 실행이나 실기기 접근성 검증을 완료했다는 근거가 아니다.
