## front-iter2 후속 (main 미반영)

`front-iter2` 에만 있는 작업이다. main 에 머지하면 위 상태에 합친다. 셋 다 실기기 확인 전이다.

- 지도 정확도·모든 수단 미리보기(10-18, `e8339ea`·`798d300`): 정적 지도 축척을 실측(`2^(lv-3)` m)으로, 좌표계를 EPSG:5181 로 고쳐 경로선이 제자리에 그려진다. 자동차·대중교통 후보도 `path` 를 실어 지도로 미리 본다([R-10](backend-requests.md)). Figma F-14.
- 캘린더 연동(10-18, `b844e80`): 가입 ⑮ 다음 ⑱ 에서 앱이 읽을 기기 캘린더를 고르고, ⑯ 설정에서 스위치로 켜고 끈다. 가져오기는 연동한 캘린더의 일정만 읽는다. 연동은 기기에만 저장한다. 자동 동기화(R-11~R-14)는 팀 결정 대기. Figma F-15(보드 재배치 포함).
- 구글·카카오 캘린더 안내(10-18, `aa0b9d1`): 동기화를 끈 캘린더를 목록에서 빼고 "캘린더가 안 보이면" 안내를 붙였다. 톡캘린더는 카카오 API 가 남이 만든 일정의 제목·장소를 주지 않아 가져올 수 없다. Figma F-16, [task.md](../../task.md) 18번.
- 집을 나섰는데 계속 "준비 중"(10-19, `ef584bf`, 팀원 제보): 나간 뒤 흐린 위치만 와도 집에서 확실히 멀어지면 이동 중으로 넘기고, 판정에 쓸 위치가 2분 끊기면 고정확도로 올린다. 근거가 낡거나 없으면 "준비 중" 을 단정하지 않는다 — 알람이 꺼진 일정은 "알람 꺼짐", 출발 예정 시각이 지나도 위치 기록이 없으면 "출발 확인 안 됨". [진행률 문서](../progress-tracking.md) §2, Figma F-17, [task.md](../../task.md) 4번. 앱 단위 테스트에 더해 에뮬레이터에서 모의 위치로 서비스·알림까지 확인했다(`TripCoarseFixTest`). 실기기는 확인 전.
